# Apex

High-performance vanilla JavaScript library for advanced text effects.

## Installation

```bash
pnpm add apex
# or
npm install apex
```

## Usage

```js
import { YugopScramble } from 'apex/String/Effects';

const scrambler = new YugopScramble(document.getElementById('title'));
scrambler.scramble('Hello World');
```

## Development

```bash
pnpm install
pnpm build
pnpm lint
pnpm dev
```
